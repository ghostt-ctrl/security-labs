This report documents the complete compromise of the Vegeta 1.0 vulnerable virtual machine. The objective was to perform reconnaissance, identify potential attack vectors, gain initial access to the system, and ultimately obtain root privileges.

Throughout the assessment, multiple enumeration techniques were used to uncover hidden information. The attack path involved web enumeration, source code analysis, decoding hidden data, extracting credentials, SSH access, and privilege escalation through local information disclosure.

This exercise demonstrates the importance of thorough enumeration and highlights how seemingly insignificant clues can lead to complete system compromise.
